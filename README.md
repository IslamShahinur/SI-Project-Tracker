== Description ==

======================================================
A lightweight WordPress plugin to track personal developer projects with progress percentage, chronological notes, and Google Drive & OneDrive reference documents.
SI Project Tracker is designed specifically for software developers, agencies, and freelancers managing multiple client projects, mobile apps, WordPress plugins, and web apps.

==========================================================================================

Key Features:
* **Interactive Dashboard**: Real-time summary cards, average completion progress, active/planning counters.
* **Project Management**: Categorize projects (Website, Plugin, Android App, iOS App, API/Backend, Desktop) with status badges and progress sliders.
* **Chronological Developer Notes**: Add dated progress logs. Posting a note can automatically bump progress % and transition status!
* **Reference Documents Table**: Attach reference files with direct integration links for **Google Drive** and **OneDrive**.
* **Clean Uninstallation**: Option to drop custom database tables on plugin deletion.

== Installation ==

1. Upload the `si-project-tracker` folder to the `/wp-content/plugins/` directory or install via WordPress Admin -> Plugins -> Add New -> Upload Plugin.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Access "SI Projects" from the WP Admin main sidebar menu.
